Interaction API capability probe

Small live calls that answer what the docs don't: does a plain Gemini model interaction work, is stream:false accepted, does the response carry usage, and does system_instruction survive previous_interaction_id. Nothing is saved. Each call sends "hi" and caps output at 16 tokens.

Runs once on page load and the result is cached, so a refresh costs nothing; the button forces a fresh run. The model list below is filled from it — the catalog never advertises Interactions support, so this is the only way to know a model can serve the interaction arm.
